# CLAUDE.md

This file guides Claude Code when working in this repository.

## What this is

An IT PMO Kanban board for tracking UOB IT project tasks. The whole app is one file, `index.html`, written in vanilla HTML, CSS and JavaScript with no build step, no dependencies and no external resources.

## Running it

Open `index.html` directly in a browser. There is nothing to install or build.

## Architecture

- **State**: a single `state` object (`tasks`, `nextNumber`, `filters`, `pendingDeleteId`, `draggingId`). Nothing is persisted: no localStorage, sessionStorage, IndexedDB or cookies. A refresh reseeds the 8 sample tasks.
- **Rendering**: `renderBoard()` rebuilds the summary strip and the four columns from `state` on every change. All user text goes through `escapeHtml()` before it reaches `innerHTML`.
- **Columns**: `backlog`, `inprogress`, `blocked`, `done` (see `COLUMNS`).
- **Task IDs**: `UOB-ITPM-####`, generated by `makeId()`.
- **Moving tasks**: HTML5 drag and drop on the lanes, plus a per-card "Move to…" select for keyboard users. Both call `moveTask()`.
- **Delete**: inline confirm on the card (`pendingDeleteId`); no `confirm()` dialogs.
- **Add Task**: form with inline validation (`validateForm`, `showErrors`). New tasks are sent to FormSubmit via `sendToFormSubmit()` using the `FORMSUBMIT_ENDPOINT` constant. The first submission to a new address needs the activation link in FormSubmit's email.
- **Overdue**: a task is overdue when its due date is before today and it is not Done.
- **Filters**: project, assignee substring and priority; the summary strip reflects the filtered set.

## Conventions

- Named functions, no frameworks, no classes.
- Colors are CSS custom properties on `:root`, with dark-mode overrides.
- Design system (from the ui-ux-pro-max "Banking / Traditional Finance" profile and the frontend-design skill): trust navy with gold reserved for the primary action and focus, Bahnschrift for headings and numbers, Segoe UI for body, sentence-case labels, 44px minimum control height. The masthead's proportional status bar is the one bold element; keep the rest quiet.

## Project skills

`.claude/skills/` holds frontend-design, ui-ux-pro-max and cybersecurity-analyst. Use the first two for UI changes and the third for the security scan in `/publish`. The ui-ux-pro-max search script needs Python 3.
- Keep the app accessible: semantic landmarks, labelled controls, visible focus, `aria-live` for the summary and form status.

## Publishing

`/publish` (in `.claude/commands/publish.md`) runs a security scan, screenshots the site with the Playwright MCP server (configured in `.mcp.json`), updates the README, sets the repo About, pushes, and deploys to GitHub Pages through `.github/workflows/pages.yml`.
